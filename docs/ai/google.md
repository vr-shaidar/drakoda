# Google AI Integration

Implement a Google adapter behind the AI Gateway.

Before implementation, verify the current official Google AI documentation for:
- Gemini APIs
- image generation/editing capabilities currently available
- Veo/video capabilities currently available
- authentication
- asynchronous operations
- input/output formats
- supported resolutions/durations
- limits
- current pricing

Do not hard-code assumptions about model availability.

Normalize Google operations into the internal generation model.
